Schedule

Rules repeat daily in . Outside a rule, Screen 1 displays Menu 1, Screen 2 displays Menu 2, and so on. TVs keep the same public URLs.

Start time is included; end time is excluded. An end time before the start time continues into the next day. Rules cannot overlap on the same screen.

Change the schedule timezone under System → Schedule timezone. This application setting is separate from the Pi’s operating-system timezone.

Offline schedules depend on the Pi clock being correct. Check it after a power interruption if this Pi has no battery-backed clock.
